
# Secretary Friend — Intelligent Productivity and Study Workspace

An all-in-one productivity and study assistant web application designed to help students streamline tasks, stay disciplined, and track learning progress with an adaptive theme system and interactive utilities.

Live Application: https://secretary-friend-ltcs.vercel.app

---

### Key Features
* Integrated Focus Chamber: Interactive Pomodoro timer with study intervals and session tracking.
* Smart Navigation and Dashboard: Centralized state handling, task counters, XP progress, and live time updates.
* Dynamic Dual Theming: Full Light and Dark mode toggling with high-contrast UI accessibility.
* Bilingual Interface: Instant language switching supporting English and Arabic layout orientations.
* Gamified Progression: Dynamic leveling system, daily discipline reminders, and quest management.

---

### Built With
* Framework: Next.js (App Router, React)
* Language: TypeScript
* Styling: CSS Variables, Tailwind CSS, Lucide Icons
* State Management: React Context API (UserContext)
* Deployment: Vercel
